# Slop Bot operating contract

Credentials, deployment identity and private conversations never belong in source.

## Product

Build the autonomous system on the existing AWS Lightsail server. Telegram is its operational interface; Codex is not a daily operator. Research primary cybersecurity/networking sources daily, select diagnostic puzzles, verify the answer, render narrated Reels, publish through the official API and learn from measured outcomes. No routine human content approvals.

Target two posts daily. Posting times are recorded experiments based on account observations, never claims of guaranteed optimal hours. Live enablement, time zones and temporary holds are deployment settings.

## Content and presentation

- Short, concrete diagnostic hooks with a real puzzle. No invented popularity claims, fake urgency, acronym recall or filler.
- Each question needs one defensible answer and plausible distractors. Keep necessary assumptions inside its accurate technical diagram.
- Preserve the approved dark navy palette, Inter typography, clean technical illustrations and readable answer choices. No watermarks, subheadings, decorative microtext or redundant instructions.
- The CTA is “Comment your answer.” Do not enumerate visible choices in the CTA.
- Natural American male narration: selected Chris voice, currently 1.08 pace. Synchronize scene changes and subtitles to actual audio. Reject silent or invalid exports.
- Show the question immediately, allow a short thinking interval, reveal and explain. Include concise relevant captions and hashtags.
- Inspect real public quiz examples when accessible; record visible evidence and distinguish it from hypotheses. Multilingual boilerplate captions are not proven growth mechanisms.

## Autonomy and long-term learning

- Save source excerpts, URLs, timestamps, provenance, plans, decisions and performance as compact text metadata.
- Block exact claim repeats across published history; apply a 50-published-Reel concept cooldown and semantic review. Rewording or renumbering is not novelty. Discovery may create new source-grounded concepts beyond the checked scenario bank. Failed factual or novelty gates mean skip, not forced publication.
- Separate creative proposals from deterministic operational checks. Source-based factual review is fallible and must not be described as executable proof.
- Persist operator preferences, experiment assignments, hypotheses and outcomes. Change one bounded production factor at a time; use comparable-age outcomes and minimum sample thresholds before adopting a challenger. No claims of proven learning before data exists.
- Durable jobs and inbox; exclusive production lock; idempotent publication; never create a second post after an unknown publication outcome. Bound source attempts, provider calls and recovery.
- Check authorization health daily and alert on invalid/expiring access. Essential credentials stay outside model prompts.

## Cost and storage

- Existing AWS server is separate from API costs. No extra paid compute or subscription without authorization.
- Cloudflare Workers Free handles conversation, research and editorial planning within a shared conservative daily quota; no automatic paid fallback.
- Explicit premium voice is permitted within $0.03/job and $1.80 per rolling 31 days. Reserve before submission, preflight the whole narration, retain uncertain charges and prevent duplicate paid requests.
- Report measured usage and reservations honestly; provider invoice reconciliation is separate. The refinement experiment ceiling is $0.06.
- No permanent media archive on Lightsail. Delete private-preview assets after Telegram receipt and published assets after Meta confirmation. Keep Telegram file IDs for resend; retain text metadata and small database backups. Do not delete unresolved publication artifacts prematurely.

## Telegram and publishing

- Authorized operators are configured locally. They share one queue and budget. Other users/groups cannot control it.
- Advertise only /budget. Normal chat supports concise status, preferences, pause/resume, scheduling and production controls through the LLM; all replies are generated by the same conversational agent using live structured state.
- Send previews and non-publication alerts only to the owner. Notify both registered private chats after confirmed publication, including the post link.
- Connect a professional Instagram account through the official API. Telegram controls live state; never put account identifiers or authorization credentials in source.

## Repository

Slop Bot is a standalone repository. Never commit secrets, runtime databases, generated media or private chat history. Resolve the latest explicit repository restriction before pushing; do not copy this project into another repository merely to bypass it.
